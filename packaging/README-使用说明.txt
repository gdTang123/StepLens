StepLens（内部使用）

解压后直接运行 StepLens.exe。请把整个目录放在一起，不要单独拷走 exe。
程序不写注册表。

一、打开文件
1. 工具栏「打开」或菜单「文件 - 打开」（Ctrl+O）
2. 把 STEP/IGES 拖进窗口
3. 命令行：StepLens.exe 文件路径
加载时有进度和「取消」。打开新文件 B 时，若已有 A：取消或失败会回到 A，不会误清 A。
加载完成后按 Esc 不会清除已成功打开的文件。空闲时取消无效。

二、视图
- 适应窗口：工具栏或 F
- 前/后/左/右/上/下/等轴测：工具栏对应按钮
- 显示模式：着色+边线、仅着色、线框

三、装配树
左侧装配树可勾选显隐。顶部搜索框按名称过滤；命中节点会保留祖先路径。清空搜索恢复全树。

四、测量
- 距离（D）：依次点选顶点/边/面，结果默认 mm、三位小数，写入右侧「测量结果」列表，并在视图画标注
- 角度（A）：直线边或平面，结果度、两位小数，同样进列表
- 清除测量（Ctrl+Delete）：同时清除视图标注和右侧列表

五、截图
工具栏「导出截图」或 Ctrl+P：导出当前三维视图为 PNG/JPG（含测量标注，不含工具栏）。

六、明确未验证（不要当成已交付）
- 空帧 / 独显稳定性
- 绿色版 zip 打包与 VC 再发行库门禁
- 退出挂起、超大装配树超时、CI / 合并 / 发布
